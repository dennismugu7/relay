# Learning guide

This folder turns the Relay repo into study material. Start here.

| Where | What you'll find | When it's written |
|---|---|---|
| [stage-1-retrospective.md](stage-1-retrospective.md) | Stage 1 in one page: what was built, the key decisions, bugs and lessons, and **what to study first** | At the end of each stage |
| [REPO_TOUR.md](REPO_TOUR.md) | A guided walk through every folder and key file | Updated whenever the structure changes |
| [journal/](journal/) | One entry per work session: what was built, why, a code walkthrough, new concepts, self-check questions | After every session |
| [bugs/](bugs/) | Every bug: symptom, investigation, root cause, fix, lesson | Whenever a bug is fixed |
| [../adr/](../adr/) | Architecture Decision Records: the big choices and their trade-offs | Whenever a real design choice is made |
| [../spikes/](../spikes/) | Small experiments that answered a "will this work?" question | Before building on an unknown |
| [GLOSSARY.md](GLOSSARY.md) | Every technical term, in plain words | Whenever a new term appears |

## Suggested way to study
1. Read the newest journal entry.
2. Open the files it points to and read the code alongside it.
3. Answer the self-check questions before opening the answers.
4. Read any bug entries from the same day: debugging is where most of the learning is.
